# 组合运动建模最终研究结果

## 1. 最终结论

组合运动已经找到能够在真值上完整解释、并在一个封存测试条件下用当前 PnP 观测有效工作的物理模型：

\[
p_j(t)=c_0+u\,\operatorname{triangle}(\phi+v t,L)
      +R_z(\omega t)R_z(\theta_0)q_j .
\]

其中 `triangle` 表示中心在有限直线路径两端反射，`q_j` 保留四块装甲板各自的半径和高度。模型直接拟合全部可见装甲板轨迹，不逐帧恢复车体中心。

一次性封存测试 `combined-04` 中，4 s 历史的直接联合模型在 50/100/200 ms 的横向（cross-depth）P95 为：

- 恒定扭转段：`22.6/22.0/30.9 mm`；
- 跨平移反转：`16.0/21.9/15.8 mm`，但样本量只有 `4/4/7`；
- 同一模型的深度 P95 为恒定段 `88.6/94.0/102.1 mm`、跨反转 `82.0/82.4/83.2 mm`。

因此，这个封存条件下横向误差通过当前 `55 mm` 诊断线，深度误差仍明显更大。该诊断线不是命中概率，跨反转样本也太少，不能外推成“所有距离、速度、角速度都已部署通过”。开发集的多条件 P95 仍高于 55 mm，非 oracle 身份、在线路径参数辨识和相位歧义 gate 也尚未完成。

## 2. 严格实验合同

开发阶段只使用：

- train：`combined-01/02/03/05`；
- validation：`combined-00`；
- test：`combined-04` 在参数和方法提交为 Git `743aa80` 后只读取一次，测试后禁止调参。

封存测试条件为：距离 `4.556 m`、线速度 `1.865 m/s`、单程行程 `3.452 m`、角速度 `+11.868 rad/s`、平移方向 `-23.185°`、时长 20 s。共同评分锚点 58 个，保留 1,720 条逐预测和 58 条逐拟合记录。

横向定义固定为 tracker 坐标中的：

\[
e_{\perp}=\sqrt{e_y^2+e_z^2},
\]

深度为 `|e_x|`。所有 signed tracker xyz、横向、深度、world planar 和三维误差均保留，报告 P50/P90/P95/P99/max，不用平均值代替完整分布。

离线实验仍用 truth slot 作为“同一块物理板”的关联句柄；它没有进入估计数值，但不是可部署关联器。

## 3. 从局部分解到最终模型的实验链

### 3.1 LOS 各向异性稳健拟合

当前 PnP 的深度长尾远大于横向误差。第一轮扫描将残差变换到 anchor tracker 坐标，横向平方权重固定为 1，深度平方权重比较 `1/0.1/0.01/0.001`，Huber delta 比较 `20/50/100 mm`。

开发集选择为深度权重 `0.1`、Huber `20 mm`。400 ms 历史、单窗估计角速度下：

- train 的横向 P95 从近似各向同性的 `119.4/140.7/222.5 mm` 改善到 `111.4/119.7/200.0 mm`；
- validation 从 `83.6/102.7/179.0 mm` 改善到 `84.3/98.4/163.9 mm`。

继续降低到 `0.01/0.001` 会退化，因此不能简单丢弃深度；`0.1` 是当前开发分布上的折中，不是新的相机通用常数。

### 3.2 角速度必须跨窗口维护

局部 400 ms PnP 窗口对低角速和远距离条件不稳定。将最近若干个因果窗口的 `omega` 取中位数后，31 窗口方案在 train/validation 的 200 ms 横向 P95 从 raw 的 `200.0/163.9 mm` 降至 `133.1/108.2 mm`。

对应角速度误差在 train 的 P50/P95 从 `0.526/3.267 rad/s` 降至 `0.162/0.858 rad/s`。这证明 `omega` 应作为慢变量维护，不能每帧独立重置。

### 3.3 “先求中心、再反射”失败

用真值中心、真值路径轴/端点/速度传播时，跨反转 clean 横向 P95 约为 `9.7/9.4/9.7 mm`，说明反射物理本身正确。

但把局部 PnP 因子化拟合中的 `c/v` 拆出来，再独立做中心反射，会出现严重退化。原因不是反射公式，而是 PnP 噪声下中心、线速度、旋转相位和半径尺度会相互补偿；局部预测可能暂时正确，却不代表每个隐变量都能单独作为可靠状态传播。这一失败结果支持“不逐帧恢复中心”的原判断，并保留在 reversal v1/v2 证据目录中。

### 3.4 直接拟合三角波平移与刚体旋转

下一方案不再恢复每帧中心，而把已配置的路径轴、速度和行程直接写入装甲板轨迹。固定真值角速度时，4 s PnP 历史在 train 跨反转的横向 P95 为 `31.3/24.0/31.6 mm`，clean 近数值精确。

把 250 ms 局部角速度直接带入 4 s 模型会累积旋转相位误差，所以最终改为在长窗内联合搜索 `omega` 与平移三角波相位 `phi`，同时线性拟合共享中心与板相位。

### 3.5 长窗联合模型的开发表现

4 s 直接联合模型的 clean train 在恒定段和跨反转均近数值精确，证明数学表达闭合。PnP train 的横向 P95 为：

- 恒定段：`87.4/96.6/122.0 mm`；
- 跨反转：`37.4/25.0/55.0 mm`，样本量 `7/18/48`。

PnP validation 为：

- 恒定段：`97.2/98.8/85.7 mm`；
- 跨反转：`17.2/88.1/240.5 mm`，样本量仅 `2/2/3`。

validation 的跨反转失败发生在 4 s 历史尚未观测到路径端点的条件；此时平移相位不可由局部直线段唯一确定。正确处理不是给一个错误的高置信单点，而是保留多个平移相位/反转时刻假设，等端点或 change point 出现后再收敛。

## 4. 封存测试的同锚点方法对比

下表均为当前 PnP、相同物理板、相同 4 s 成熟轨迹锚点上的横向 P95，单位 mm。恒定段样本量为 `53/54/50`，跨反转为 `4/4/7`。

| 方法 | 恒定段 50/100/200 ms | 跨反转 50/100/200 ms |
| --- | ---: | ---: |
| hold | 169.7 / 309.9 / 499.9 | 257.1 / 272.3 / 367.2 |
| same-slot world CV | 304.8 / 448.4 / 654.1 | 219.7 / 432.2 / 567.0 |
| v1 各向同性单窗因子化 | 101.8 / 166.5 / 351.6 | 58.5 / 177.2 / 426.9 |
| LOS + 31 窗口 `omega` | 36.0 / 41.5 / 52.0 | 27.0 / 127.2 / 323.0 |
| 4 s 直接联合 `omega+phi` | **22.6 / 22.0 / 30.9** | **16.0 / 21.9 / 15.8** |
| 直接模型 + oracle `omega` | 10.7 / 11.9 / 14.8 | 7.7 / 7.4 / 11.5 |

封存测试中的角速度绝对误差 P50/P95 为：

- v1 各向同性单窗：`0.627/2.154 rad/s`；
- LOS 单窗：`0.456/1.217 rad/s`；
- LOS 31 窗口：`0.088/0.244 rad/s`；
- 4 s 直接联合：`0.030/0.052 rad/s`。

长窗联合模型不是靠“平滑预测结果”获胜，而是把平移反转相位和旋转相位放在同一条刚体轨迹上联合解释。

## 5. 与 CV 和 11 维 EKF 的关系

以前的真值历史消融中，world-CV 对 combined 为 `97.9/182.0/344.7 mm`，开源 `rm_vision` 风格 11 维展开 EKF 为 `88.6/133.9/215.1 mm`；当前 PnP 输入下裸 EKF 是米级失败。那些数字来自不同的样本合同，不能与本次封存测试逐项相减，但结论一致：

1. 普通 CV 即使输入真值也无法表示“中心平移 + 板绕中心旋转 + 有界反转”。
2. 通用单模态 EKF 的状态结构和固定 Q/R 不会自动解决不可观测性、错误身份和非高斯深度长尾。
3. 组合运动需要专门的物理因子化与离散相位/模式假设；滤波器只能服务于这个模型，不能替代模型。

## 6. 最终建议的预测器结构

最终选择是分层混合模型，不是神经网络或普通 11 维 EKF：

1. **局部层**：400 ms LOS 各向异性 Huber 因子化拟合，`omega` 用 31 个因果窗口中位数维护；恒定扭转或短轨迹使用。
2. **长窗层**：4 s 直接拟合“有界直线三角波 + 刚体旋转”，联合估计 `omega` 和平移相位；已观测到端点/反转后使用。
3. **模式层**：端点尚未观测、相位多解时保留多个反转时刻假设，并把歧义传给 fire-control gate；禁止用任意单解冒充高置信预测。
4. **观测层**：保留四板不同几何、LOS 各向异性误差与物理身份，不逐帧求中心，不把 raw depth 当高置信车辆中心输入。

## 7. 尚未完成的部署条件

本阶段研究问题已经可以关闭，但以下工程门禁仍然存在：

- 当前评分使用 truth slot 身份；需要非 oracle 的物理板关联与 reacquisition。
- 直接模型使用已配置的平移轴、速度和行程；真实目标需要在线辨识及不确定度。
- 需要可部署的相位多峰度/change-point gate，决定何时从局部层切换到长窗层。
- 开发集多条件 P95 仍未全部进入 55 mm，必须增加距离、速度、正反角速度和端点覆盖后再做正式系统验收。
- 深度 P95 仍约 0.1 m，虽然对当前横向 gate 影响较小，但会影响弹道时间、三维关联和中心几何。
- 还未接入在线 `RobotEstimator` 或 fire control；本次只完成离线因果研究和封存测试。
