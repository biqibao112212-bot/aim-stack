# 未来装甲板位置预测评价标准 V1

标准标识为 `AUTOAIM_FUTURE_ARMOR_PREDICTION_V1`，机读配置见
[`prediction_evaluation_standard_v1.json`](prediction_evaluation_standard_v1.json)。

## 评价对象

在曝光时刻 `t` 完成当前帧更新后，立即冻结一份滤波器后验状态和当前装甲板的
物理身份。预测器只使用 `t` 时刻及此前已经可得的信息，按生产运动模型将状态
外推到 `t + τ`，解码出同一块物理装甲板的未来位置。

之后，离线评价器读取 `t + τ` 附近的后续真值曝光，并计算：

```text
e(t, τ) = predicted_armor(t + τ | state_at_t) - truth_armor(t + τ)
```

后续真值只进入离线评价器，不回写 detector、PnP、tracker 或预测器。

## 时间和物理身份

- 必报预测时域为 `100 / 200 / 300 / 500 ms`；`0 ms` 作为当前后验误差诊断点。
- 预测起点是曝光时间戳对应的当前帧更新后状态，不是评价程序的墙钟运行时刻。
- 若跟踪器输出稳定的装甲板身份，直接使用该身份。若基线实现没有输出身份，
  评价器可在预测已经输出后，用 `t` 时刻真值将一个解码候选映射到物理装甲板；
  该映射只确定评价对象，不改变预测值。
- `t + τ` 介于两次真值曝光之间时，可对中心和展开后的 yaw 做线性插值。两端曝光间隔
  不得超过 `25 ms`。
- 每个时域同时报告有效样本数和可用率。

## 误差坐标和必报统计量

在未来真值装甲板处建立局部坐标：

- `normal_radial`：水平面内从车体中心指向装甲板的法向/径向；
- `tangential`：装甲板板面内的水平轴；
- `vertical`：装甲板板面内的竖直轴，与 tracker `+z` 一致；
- `euclidean_3d`：三维误差范数。

每个必报时域至少输出四类绝对误差的 `p50 / p95`、有效样本数、可用率和板面窗口覆盖率。

## 装甲板窗口

| 类型 | 宽 × 高 | 中心允许的水平偏差 | 中心允许的竖直偏差 |
| --- | ---: | ---: | ---: |
| 小装甲板 | `135 × 55 mm` | `|e_t| ≤ 67.5 mm` | `|e_z| ≤ 27.5 mm` |
| 大装甲板 | `225 × 55 mm` | `|e_t| ≤ 112.5 mm` | `|e_z| ≤ 27.5 mm` |

板面窗口覆盖率的单样本判定为：

```text
inside = |tangential_error| <= armor_width / 2
      and |vertical_error|   <= armor_height / 2
```

这一覆盖率表示预测点在理想装甲板平面上的几何窗口表现。法向/深度误差用于距离和
弹道评价；实际命中还需在同一板面坐标内加入云台跟随、弹道解、发射时序和弹丸散布误差。

## 报告与可复现性

评价产物必须保存数据集/采集锁、代码提交、场景参数、处理频率、样本数、真值插值与排除规则，
并导出机读的全时域汇总。不同滤波器、观测器或运动模型使用同一标准和同一批时间锚点比较。
