# 组合运动：PnP 下游压误差与分层因果消融

## 1. 先说结论

这轮不是又换一个预测器，而是在已经验证过的 4 s 直接联合物理模型上回答三个问题：

1. 当前 PnP 输入能否由下游的低容量校正继续压低误差？
2. 压不下去的部分主要来自 tracker 深度 `x`、横向水平 `y`、竖直 `z`，还是运动状态拟合？
3. PnP 需要改善到什么程度，大部分组合运动预测才能进入当前 `55 mm` 的 tracker-`y/z` 合向量诊断门限？

正式结果是：

- 下游校正**有明确价值，但没有完全解决**。跨 session 的观测-yaw 谐波校正把常规恒扭段 50/100/200 ms 的 55 mm 逐点覆盖率从 `25.3%/25.8%/27.0%` 提高到 `58.6%/53.5%/43.8%`。
- 改善发生在完整主体分布，不只是某个 P95：相对 raw PnP，逐样本变好的比例为 `82.1%/77.1%/69.4%`，但仍有 `17.9%/22.9%/30.6%` 变差。
- 尾部仍没有闭合。校正后的 P90 为 `182.0/210.6/257.3 mm`，P95 为 `261.7/295.5/371.2 mm`。
- tracker-`y` 是当前组合预测的主导因果坐标。只把历史 `y` 复原为真值，55 mm 覆盖率就达到 `91.1%/89.1%/84.9%`；只复原深度 `x` 或竖直 `z` 几乎不能产生同等级改善。
- 统一保留 25% 的当前 PnP 残差，即把 PnP 误差整体缩小约 75%，可让 `78.7%/79.5%/74.0%` 的预测进入门限；但 P90 仍为 `76.1/77.2/90.4 mm`。因此“让大部分点可用”和“让 90% 条件稳定通过”是两个不同目标。
- 跨反转仍是独立难题。即使历史位置完全精确，真正跨过平移反转点时，clean P95 也会从 50 ms 的 `24.1 mm` 增长到 100/200 ms 的 `142.1/342.3 mm`。PnP 优化不能提供尚未发生的反转时刻。

因此，当前优先级不是继续调 EKF、继续加谐波阶数或只修深度，而是：

1. 保留下游低容量校正作为离线候选，并在新 session 上独立验证；
2. 把角点/PnP 优化目标转向 tracker-`y` 或 truth-depth hit-plane 误差；
3. 对长尾建立可解释的拒绝、不确定性或条件门禁；
4. 把反转时刻/模式多假设作为与 PnP 分离的问题处理。

## 2. 指标和条件必须先说清楚

主指标是用户定义的“深度以外另外两个 tracker 分量的合向量”：

```text
cross_depth_error = sqrt(error_tracker_y^2 + error_tracker_z^2)
```

当前坐标约定为：

- tracker `x`：前向/深度；
- tracker `y`：左右横向；
- tracker `z`：上下；
- `55 mm`：当前诊断门限，不是实弹命中概率。

所有 50/100/200 ms 都是从 anchor 时刻开始的固定未来偏移：

```text
future_time = anchor_time + horizon
```

它们不是距离除以弹速，没有输入弹速，也没有运行弹道求解器。

本轮仍使用 offline truth slot 对历史观测做物理板关联和评分，因此结果是 oracle-identity 上界，不是完整在线系统结果。

### 3.2 校正器切分

144 条 session 按 `sha256(session_id) mod 5` 固定成五折。每一个被评分 session 的校正模型只用另外四折拟合，不存在随机分帧把同一轨迹同时放进训练和测试的问题。

校正器只使用在线观测流已有字段：

- selected PnP tracker `x/y/z`；
- range、cross-range、range²；
- `camera_profile_id`；
- `yaw_absolute_rad` 的 1--4 阶正余弦和 range 交互项。

模型是低容量 robust Ridge/IRLS：

- Ridge `lambda=1e-3`；
- 5 次 IRLS；
- Huber `delta=0.1 m`；
- robust norm 的深度权重为 `0.1`。

truth 只用于训练残差标签和预测后评分。truth slot、truth radial phase 只在 oracle 消融中使用。

## 8. 哪一层在主导误差

### 8.1 坐标真值复原

- `truth_depth_only`：50/100/200 ms 的 55 mm 覆盖仅为 `25.2%/27.6%/28.9%`，与 raw 基本相同；
- `truth_tracker_z_only`：覆盖为 `28.0%/29.3%/30.2%`，仍与 raw 接近；
- `truth_tracker_y_only`：覆盖跃升到 `91.1%/89.1%/84.9%`；
- `truth_cross_depth_yz`：仅在 `y-only` 基础上小幅变化。

所以，对当前命中相关合向量来说：

```text
tracker-y 误差 >> tracker-z 误差；depth-x 不是主要直接瓶颈
```

深度对 3D pose 很重要，但这份因果消融否定了“先把深度长尾压好就会自然解决当前横向预测”的优先级假设。

### 8.2 状态角速度

所有 2,491 个唯一 anchor 上的 `|omega error|` P50/P95：

| 输入 | P50 | P95 | 方向正确率 |
| --- | ---: | ---: | ---: |
| raw PnP | 0.180 rad/s | 0.445 rad/s | 99.76% |
| yaw harmonic | 0.119 rad/s | 0.417 rad/s | 99.80% |
| alpha=0.25 | 0.076 rad/s | 0.209 rad/s | 99.64% |
| truth tracker-y | 0.046 rad/s | 0.168 rad/s | 99.76% |
| clean exact | 0.000020 rad/s | 0.000121 rad/s | 99.44% |

校正对角速度有一定帮助，但远小于它对当前位置/相位偏差的主体改善；剩余预测误差不能只归因于 `omega`。

## 9. 需要多大 PnP 改善

`p_alpha = truth + alpha * (PnP - truth)` 保持时间戳、缺失、可见弧、anchor 和 slot 不变：

| 剩余残差 | 50 ms P50/P90；gate | 100 ms P50/P90；gate | 200 ms P50/P90；gate |
| --- | ---: | ---: | ---: |
| 100%（raw） | 103.0/276.3 mm；25.3% | 102.6/293.0 mm；25.8% | 105.7/319.3 mm；27.0% |
| 75% | 79.5/212.4 mm；34.1% | 76.8/220.2 mm；36.6% | 78.8/235.9 mm；36.9% |
| 50% | 53.4/144.8 mm；50.8% | 52.1/147.5 mm；51.8% | 53.2/168.2 mm；51.4% |
| 25% | 28.3/76.1 mm；78.7% | 27.1/77.2 mm；79.5% | 28.4/90.4 mm；74.0% |
| 0%（clean） | 0.004/0.024 mm；98.9% | 0.004/0.029 mm；98.4% | 0.005/0.044 mm；97.7% |

严格结论是：

- 若目标是“超过一半预测进入 55 mm”，整体 PnP 残差约减半已经接近；
- 若目标是“约四分之三预测进入 55 mm”，需要约 75% 的整体残差缩减；
- 若目标是 P90 进入 55 mm，当前扫描到 `alpha=0.25` 仍不够；本轮没有事后增加 alpha 网格，因此不能伪造更精确阈值。

## 11. 下游继续尝试了什么，为什么停止

### 11.1 affine 与观测-yaw 谐波

两者都通过整 session 外推；yaw harmonic 在当前观测 P50、P90 和 55 mm 覆盖上优于 affine，因此进入预测回放。

### 11.2 oracle slot / truth phase

边际收益很小，说明继续把资源优先投入 slot-conditioned 单帧修正不合理。

### 11.3 嵌套后处理

每个 outer fold 只用另外四折做内层选择，候选包括：

- 全 XYZ、只 y/z、只 y；
- 0.5/0.75/1.0 blend；
- 0.1/0.2/0.4 m 和无限 correction cap。

五折全部选择“只 y/z、全强度、不限幅”。但当前 `y/z` 指标对 depth 不敏感，因此它与全 XYZ 校正完全打平，不能称为额外测量改善。

### 11.4 y/z-only 未来预测 probe

y/z-only 相对 full XYZ：

- 50/100/200 ms 中位数从 `43.8/49.5/67.3` 改到 `42.8/48.4/64.5 mm`；
- 55 mm 覆盖从 `58.6/53.5/43.8%` 改到 `58.9/54.6/44.8%`；
- 但 100/200 ms P90/P95 略微变差。

它没有通过预注册的“每个时域 P50/P90/P95 和 gate 全部不劣”规则。因此正式保留 full XYZ yaw-harmonic；y/z-only 作为主体略好、尾部略差的负证据。

## 12. 角点层如何与本轮因果证据连接

历史 exact-corner 消融使用不变的 IPPE 和坐标链：

| 角点输入 | PnP 3D P50/P95/P99 | PnP lateral P50/P95/P99 |
| --- | ---: | ---: |
| exact projected corners | 0.003/0.009/0.012 mm | 0.00016/0.00042/0.00061 mm |
| actual raw corners | 142.9/458.3/605.2 mm | 7.9/21.3/29.0 mm |
| actual refined corners | 140.8/500.3/708.5 mm | 6.7/25.0/35.0 mm |

所以 exact corners 能让 solver 数值闭合，而现有 refinement 只略微改善 3D 中位数，却恶化 P95/P99 和 lateral 尾部。

正式 144-session `stage3-observation-v1` 没有保存 raw/refined corners、候选和 corner covariance，因此不能声称完成了同一帧的“角点真值→组合预测”全链消融。严谨的证据链是：

```text
exact-corner 历史证据：角点精确时 PnP 可闭合
          ↓
144-session PnP 坐标消融：tracker-y 是未来横向预测主瓶颈
          ↓
优化目标：角点/PnP 应按 tracker-y 或 hit-plane 方向敏感误差验收
```

这不等于“任意让像素 RMS 更小就会改善预测”。历史 refinement 和 joint PnP 已经否定了这种简单关系。

## 13. 条件分层与剩余长尾

- 100 ms 时，近/中/远距离校正后的 P50 为 `51.9/44.4/56.6 mm`，P95 为 `281.1/293.2/343.8 mm`；远距离更差，但近距离同样没有完全解决。
- 8 个方向扇区的校正后 100 ms P50 为 `22.8--69.5 mm`，55 mm 覆盖为 `39.4--74.3%`，说明相对 LOS 的运动方向仍是重要条件。
- `precision_16mm` 常规 100 ms anchor 只有 54 条，校正后 P50/P95 为 `58.8/330.4 mm`；样本太少，不能用它声明 16 mm 相机正常性能。
- 线速度档与绝对角速度档在数据设计中完全耦合，不能分别做独立因果归因。

长尾下一步应优先按 direction、camera profile、斜视/可见弧和角点模式做 calibrated support/gating，而不是事后提高回归阶数。

## 15. 当前决策

可以接受：

1. 当前 PnP 下游仍有可迁移、低容量的系统偏差可利用；
2. yaw-harmonic correction 对大部分恒扭组合预测有显著改善；
3. tracker-y 是当前命中相关预测的主导坐标瓶颈；
4. 约 75% 的整体 PnP 残差缩减可让约四分之三预测进入 55 mm，但不能让 P90 通过；
5. 反转时刻/模式是独立于 PnP 的未来信息问题。

不能接受：

1. 不能声称校正器已经可部署；它仍有米级 P99/max 和条件退化；
2. 不能声称 current PnP 对组合运动已经足够；
3. 不能把 depth 3D 长尾直接等同于 tracker-`y/z` 命中误差；
4. 不能用 oracle slot/phase 的微小收益支持复杂身份条件修正；
5. 不能用本轮 PnP 坐标消融冒充正式 144-session 的同帧角点消融；
6. 不能把 55 mm CDF 称为实弹命中率。
