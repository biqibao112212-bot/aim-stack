# 组合运动直接联合模型：约束、泛化验证与结论边界

## 1. 这次验证回答了什么

本报告验证的是已经冻结的组合运动长窗口模型，不是重新选模型或调参。验证对象是 Stage3 正式 360 条会话中的全部 144 条 `linear_and_spin` 会话，每条 30 s。模型、4 s 历史、损失函数、角速度与平移相位搜索范围均在读取结果前冻结；本次结果不允许回头调参。

结论分成两层，不能混在一起：

1. **物理表达层**：在可见性匹配的精确历史位置上，该模型对普通恒扭转段通常接近数值精确，证明“有界直线平移 + 四板刚体旋转”的表达成立；但未充分观测到换向相位时仍有长尾，200 ms 跨换向还不够可靠。
2. **当前观测层**：在这批 2026-07-20 的正式混合相机数据上，PnP 本身存在百毫米到米级长尾。联合模型明显优于 hold 和同板 CV，却远未进入 55 mm 横向诊断线，不能据此部署。

这不推翻 `combined-04` 单条新 fixed-6-mm 封存测试的 `22.6/22.0/30.9 mm`；它说明该单条件结果不能外推到旧正式集的全部距离、方向、相机配置和观测质量。大规模验证的价值正是暴露这个域差异。

## 2. 模型到底是什么

对第 $j$ 块装甲板，在锚点时刻记 $t=0$，模型为：

\[
\hat p_j(t)=c_a
+u\left[T(\phi+v t;L)-T(\phi;L)\right]
+R_z(\omega t)R_z(\theta)q_j .
\]

其中：

- $c_a$ 是锚点时刻的共享车体中心；
- $u=[\cos\gamma,\sin\gamma,0]^\mathsf T$ 是配置的平移轴；
- $v$ 是配置的正线速度幅值；
- $L$ 是配置的单程行程；
- $T(x;L)=L-|((x\bmod 2L)-L)|$ 是周期为 $2L$ 的三角波，自动表达在路径两端的镜面换向；
- $q_j$ 是第 $j$ 块板的 chassis-local 三维几何，因此四块板不同的半径和高度均被保留；
- $\omega$ 是 4 s 窗口内共享的恒定角速度；
- $\phi$ 是三角波平移相位；
- $\theta$ 是锚点时刻的共享旋转相位。

实现中不直接约束一个单位长度的 $R_z(\theta)$，而是线性拟合共享的 $C=\rho\cos\theta$、$S=\rho\sin\theta$。这允许一个全局的平面半径尺度 $\rho$ 吸收小的共同几何尺度误差，但不会允许四块板各自随意改变半径，更不会给每一帧独立中心。

这是一个 4 s 因果滑窗上的结构化鲁棒拟合器，不是 EKF，也不是神经网络：没有递归协方差、过程噪声 $Q$、观测噪声 $R$ 或学习权重。

## 3. 用了哪些约束

### 3.1 刚体和几何硬约束

- 四块板共享同一个中心、同一个 yaw 相位和同一个 yaw 角速度。
- 每块板使用自己的固定 $q_j$，保留偶/奇板不同半径与高度。
- 不允许每帧单独恢复中心、线速度或板半径，避免单板/双板条件下隐变量相互补偿。
- 只建模绕 world-z 的平面旋转；不建模车体 roll/pitch、悬挂运动或板几何变形。

### 3.2 平移运动硬约束

- 中心只能沿一个固定水平轴 $u$ 运动。
- 速度幅值在 4 s 内恒定，方向只允许在两端反转。
- 行程被限制为 $L$，平移轨迹必须是三角波而不是无界 CV。
- 不建模加速度、侧滑、曲线路径、速度突变或行程变化。

### 3.3 强配置先验

当前离线模型直接读取：

- `direction_deg` 作为平移轴；
- `linear_speed_mps` 作为线速度幅值；
- `linear_span_m` 作为单程行程；
- 精确元数据中的四板 chassis-local 几何。

因此这不是“从 PnP 独立恢复全部车体运动参数”的结果。真实部署必须在线估计这些量及其不确定度，或者由可靠的上游配置提供。

### 3.4 搜索与线性约束

- $\omega$ 先在 `[-16, 16] rad/s` 上以 `1 rad/s` 网格搜索，再在最佳网格邻域连续细化。
- $\phi$ 在 `[0, 2L)` 上用 25 个候选搜索，再在最佳候选邻域连续细化。
- 固定 $\omega,\phi$ 后，$c_a,C,S$ 由一个共享线性最小二乘问题求解。
- PnP 输入最后用 20 mm 向量 Huber 损失进行鲁棒重拟合；干净真值消融用普通最小二乘。

### 3.5 LOS 各向异性约束

残差先变换到锚点 tracker 坐标。优化权重为：

\[
\|r\|_W^2=0.1r_x^2+r_y^2+r_z^2,
\]

其中 tracker-x 是深度，tracker-y/z 构成横向。深度没有被丢弃，只是平方权重降为横向的 0.1，以减少 PnP 深度长尾对瞄准横向的污染。

### 3.6 因果约束

- 估计器只读取锚点及以前 4 s 的历史。
- 全部时间计算使用真实 `timestamp_ns`，不假设固定帧率。
- 50/100/200 ms 是三组固定预测时域，不是“距离除以弹速”得到的飞行时间；实际火控需要另行把弹道时间映射到预测时域。
- 未来真值只用于评分和事后标注是否跨换向，不进入参数拟合。

### 3.7 观测与离线评测约束

- `clean` 消融不是输入未来真值，而是把历史 PnP 位置替换为同时间、同可见性掩码下的历史真实板位置。
- truth slot 只用于离线关联“同一块物理板”和评分；它是明确的非部署 oracle。
- 无当前观测、历史可见跨度不足 4 s、CV 历史不足的锚点均计入覆盖率，不静默删除。

## 4. 为什么不用“先求中心再预测”

单板时，中心、板相位和半径本来就不能独立稳定恢复；双板正交时，PnP 深度和横向误差仍会把中心严重污染。局部窗口内即使装甲板未来位置拟合得暂时正确，拆出的中心和线速度也可能只是隐变量之间的补偿，不能安全传播到换向以后。

当前方法直接让所有可见板共同解释一条物理轨迹，只保留一个共享中心和一套旋转相位，不制造逐帧中心状态。这正是它相对中心优先方案的主要约束收益。

## 5. 大规模验证合同

### 5.1 条件覆盖

- 会话：144 条独立组合运动会话，每条 30 s；144/144 成功完成。
- 距离：`1.038–7.989 m`，近/中/远各 48 条。
- 线速度：`0.139–2.992 m/s`。
- 角速度：`-14.862–14.964 rad/s`，正反转均有。
- 平移方向：8 个扇区，每个 18 条。
- 行程：全部为 `8 m`。
- 相机观测记录：`wide_6mm` 394,505 帧，`precision_16mm` 89,033 帧。

一个重要设计限制是：线速度档与绝对角速度档完全耦合——`0–1 m/s` 总是对应 `0–5 rad/s`，`1–2` 对应 `5–10`，`2–3` 对应 `10–15`。所以本数据能验证联合条件泛化，但不能把“速度效应”和“角速度效应”做独立因果归因。

### 5.2 锚点采样

- 常规集：历史成熟后每 2 s 取一个锚点，减少同一会话高频相邻帧造成的伪样本膨胀。
- 换向压力集：每个真实换向点前约 50/100/200 ms 额外取锚点，单独报告，不混入常规分布。
- 三个预测时域：50/100/200 ms。
- 所有方法使用同一公共锚点、同一目标板、同一未来真值。

### 5.3 方法与消融

- PnP hold。
- PnP 同一物理板 400 ms world-CV。
- PnP 4 s 直接联合模型。
- PnP 直接模型 + truth `omega`，用于判断角速度误差是否是主因。
- 上述方法的可见性匹配 clean 版本，用于分离 PnP 误差与模型误差。

## 6. 数据质量和方法覆盖率

原始正式集在运动开始后共有 484,595 个有效真值帧，其中 323,691 帧有至少一个成功关联的观测，160,904 帧无观测；共保留 465,311 个关联观测事件。有效候选数完整直方图为：

| 每帧有效候选数 | 0 | 1 | 2 | 3 | 4 | 5 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 帧数 | 159,832 | 184,786 | 136,620 | 1,855 | 430 | 15 |

时间戳重复、观测/真值时间戳不匹配、tracker world transform 不匹配和关联严格歧义均为 0；15 个大于四候选的帧被显式记录并排除。

| 采样层 | 计划锚点 | 公共锚点评估成功 | 无当前 PnP | 历史可见跨度不足 4 s |
| --- | ---: | ---: | ---: | ---: |
| 常规 2 s 网格 | 1,976 | 1,315（66.5%） | 629（31.8%） | 32（1.6%） |
| 换向压力集 | 2,146 | 1,185（55.2%） | 921（42.9%） | 40（1.9%） |

144 条会话均有至少一个常规公共锚点；4 条会话没有可评估的换向压力锚点。由此可见，“模型可计算”本身不是 100%，特别是在换向附近。

## 7. 常规恒扭转段结果

下表是逐预测点横向误差 P50/P95/P99，单位 mm。完整 54,760 条预测仍保存在压缩分布中。

| 输入与方法 | 50 ms | 100 ms | 200 ms |
| --- | ---: | ---: | ---: |
| clean 直接联合 | 0.004 / 0.076 / 83.5 | 0.004 / 0.412 / 150.5 | 0.005 / 1.432 / 193.1 |
| clean hold | 44.1 / 210.1 / 256.5 | 79.3 / 396.9 / 501.2 | 150.8 / 651.7 / 861.1 |
| clean 同板 CV | 35.5 / 270.4 / 328.7 | 64.8 / 402.0 / 468.4 | 133.2 / 605.6 / 808.2 |
| PnP 直接联合 | **103.0 / 356.2 / 591.2** | **102.6 / 381.3 / 677.6** | **105.7 / 440.7 / 741.6** |
| PnP hold | 137.2 / 521.8 / 1558.5 | 173.6 / 626.4 / 1597.4 | 231.7 / 871.4 / 1400.3 |
| PnP 同板 CV | 162.1 / 995.6 / 2666.0 | 192.3 / 1428.7 / 4204.3 | 270.3 / 2142.9 / 6302.5 |

解释：

- 在 clean 历史的主体分布中，直接模型正确表达了组合运动；CV 即使输入真值也无法同时外推中心平移和板旋转。
- clean 的 P95 很小但 P99 突然增大，说明约 1% 条件仍会落入错误角速度/平移相位极小值，不能只看中位数或 P95 后宣布完全解决。
- PnP 直接模型相对 PnP hold 的 P95 降低约 31.7%/39.1%/49.4%，说明物理约束有效；但绝对误差仍远大于 55 mm。
- PnP 直接模型逐点通过 55 mm 的比例仅 25.3%/25.8%/27.0%。按会话先算 P95 后，144 条会话中通过数为 3/0/0。

## 8. 换向压力集结果

只统计预测区间真正跨过换向点的样本：

| 输入 | 50 ms：n / P50 / P95 / 通过率 | 100 ms：n / P50 / P95 / 通过率 | 200 ms：n / P50 / P95 / 通过率 |
| --- | ---: | ---: | ---: |
| clean 直接联合 | 197 / 0.032 / 24.1 / 98.5% | 572 / 0.035 / 142.1 / 80.2% | 926 / 0.037 / 342.3 / 66.3% |
| PnP 直接联合 | 197 / 156.6 / 725.9 / 10.7% | 572 / 133.9 / 694.9 / 23.6% | 926 / 156.6 / 730.9 / 21.1% |

clean 中位数仍近乎精确，但长时域 P95 很差。这证明数学模型本身能表达正确轨迹，却不保证有限可见历史能唯一选中正确的换向相位。特别是在 4 s 历史尚未包含足够端点/change point、可见板单一或平移与旋转局部互相补偿时，应保留多相位假设或拒绝给出高置信单点，不能强行输出一个相位。

## 9. PnP 与角速度消融

从同一常规锚点的 PnP hold 与 clean hold 的 signed tracker 误差相减，可得到当前帧 PnP 观测误差：

| 相机配置 | 锚点数 | 横向 P50 / P95 / P99 | 深度 P50 / P95 |
| --- | ---: | ---: | ---: |
| `wide_6mm` | 1,179 | 104.6 / 421.3 / 726.8 mm | 298.8 / 1484.2 mm |
| `precision_16mm` | 52 | 175.3 / 6163.6 / 8046.7 mm | 494.5 / 17155.4 mm |

`precision_16mm` 的常规锚点样本只有 52，且含极端异常，不能拿它估计稳定的 16 mm 正常性能；但这些异常必须作为正式集泛化失败保留。

联合模型对 `omega` 的估计其实并非主要瓶颈：

- clean `|omega error|` P50/P95 为近似 `0/0.00012 rad/s`，符号正确率 99.44%；
- PnP 为 `0.180/0.445 rad/s`，符号正确率 99.76%；
- 将 PnP 模型直接换成 truth `omega` 后，常规恒扭转 P95 仍为约 `353.1/378.4/402.4 mm`。

所以“大量误差只要把角速度滤得更准就会消失”不成立。当前正式集的主瓶颈是 PnP 位置长尾、可见性和相位/隐变量可辨识性。

## 10. 条件泛化与不可分辨因素

- PnP 直接模型的近/中/远 P95 在 200 ms 分别约 `402/406/519 mm`，远距离最差，但近距离也明显失败；不能把问题只归因于距离。
- 8 个方向扇区差异明显，200 ms P95 从约 `214 mm` 到 `624 mm`，说明路径相对 LOS 的方向会改变横向/深度误差投影。
- 线速度和绝对角速度档在数据设计中完全耦合，不能分别声称“高速更容易”或“高角速度更容易”。高档 clean 结果更好，与 `L/v <= 4 s`、历史更可能包含换向点一致，但这里只能称为解释一致性，不能称为独立因果证明。
- 常规相机配置也不是一个纯粹的会话级因素，而会在会话内变化；相机分层结果是锚点条件结果。

## 11. 当前可接受和不可接受的结论

可以接受：

1. “有界直线三角波平移 + 四板共享刚体旋转”是正确且高度可解释的 clean 物理表达。
2. 直接联合拟合优于逐帧求中心，也显著优于 hold/CV。
3. 4 s 历史已观察到足够相位信息时，它可作为组合运动成熟轨迹专家。
4. 跨换向必须显式维护相位/模式多假设或激活 gate。

不能接受：

1. 不能说当前 PnP 在全部组合运动条件下已经够用；本正式集明确否定了这一点。
2. 不能说模型已在 55 mm 门限下通过大规模部署验收。
3. 不能把 50/100/200 ms 当作自动按距离得到的弹丸飞行时间。
4. 不能把 truth slot、配置路径轴/速度/行程当成部署时免费可得状态。
5. 不能把 `precision_16mm` 的 52 个异常锚点当成完整相机性能测评。
6. 不能从当前耦合设计分别归因线速度和角速度的影响。

## 12. 下一步应做什么

模型方向无需再回到普通 CV 或通用 11 维 EKF。后续最有价值的是：

1. 在当前生产 PnP 版本上重新采一套大规模、单一相机配置、版本锁定的数据，确认 2026-07-20 正式集与 2026-07-29 fixed-6-mm 集之间的观测域差异。
2. 设计线速度与绝对角速度独立全因子网格，解除本次完全耦合。
3. 实现多平移相位/下一换向时刻假设，而不是单最优 `phi`；用 change-point 或相位峰度决定能否输出单点。
4. 替换 truth slot，验证非 oracle 四板身份关联、切板与重捕获。
5. 在线估计路径轴、速度、行程及协方差，再把 50/100/200 ms 替换为真实弹道时间查询。
