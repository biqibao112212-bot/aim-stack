# 阶段三：因果物理 A/B 模型

## 目标

本实验只回答一个问题：在不使用 PnP 坐标、未来真值或精确运动状态作为输入时，最近的连续物理位置观测能否支持一个误差数量级足够小的刚体预测器。

输入只有四块装甲板的历史精确位置、固定循环槽位、真实事件时间、有效掩码和任意查询时间 `tau`。输出仍是查询时刻四块装甲板的位置。精确质心、线速度、朝向、角速度、运动类别和未来标签均禁止进入预测器。

该实验是物理输入条件下的上限实验。固定槽位来自“外部因果槽位跟踪器正确”的假设，并不证明当前 PnP/在线身份关联已经解决，因此模型暂不属于可部署资产。

## 数据资格

数据复用 `stage3-truth-history-v1-20260721-r5` 的 train/validation，不重新采集，也不访问 test。

每个窗口执行以下因果门禁：

1. 仅保留最后一次异常时间间隔之后的连续后缀；异常间隔定义为大于本窗口正时间差中位数的 2.5 倍。
2. 重建后的新段至少积累 8 个事件；不足时不训练、不预测。
3. 每个历史事件必须与 `t0` 属于同一 producer epoch、target id 和 geometry hash。
4. 最近 4 个事件到 `t0` 必须属于同一恒定线速度/角速度段；否则输入中没有运动切换后的证据，样本不可因果预测。
5. 训练与评估固定使用 `relative_slot=0..3`，不穷举 24 种排列，也不允许指标自动重配槽位。

严格 pilot 共选择 8 个 session，训练/验证各覆盖静止、平移、旋转、平移+旋转。原始 3,509 个窗口保留 2,690 个，其中 812 个因重建后不足 8 个事件被拒绝，7 个因历史到 `t0` 发生运动切换被拒绝。保留的 173,449 个历史事件全部通过身份与几何连续性检查。

## 模型结构

模型不是让通用 TCN 从绝对坐标重新学习匀速刚体方程，而是由两层组成：

1. **因果物理主路径**：用最近 4 个固定槽位观测做二维刚体 Procrustes 对齐，得到每个事件的平移与朝向；再按真实时间做最小二乘常运动拟合，并对任意 `tau` 解码四板位置。拟合仅使用历史输入。
2. **神经残差路径**：不直接输出速度或角速度，而是从完整不等间隔历史编码中输出相对于物理主路径的共享平移/旋转残差。残差末层以零初始化，最终位置始终经过硬刚体解码。

零时刻位姿和几何不再由网络凭空猜测。若最后观测早于 `t0`，物理主路径使用真实时间跨度传播到 `t0`，不会把旧观测误当成零时刻。

## A/B 定义

- A：固定槽位的 `q0 + future absolute + motion delta` 监督，其中 q0 权重为 2。
- B：与 A 完全相同的模型、初始化、批次、随机数和优化预算，额外加入同一连续段的历史重建损失和共享常运动一致性损失。

两组 checkpoint 只按共同的固定槽位物理指标选择，不能用不同量纲的训练损失互相比较。

## Pilot 量化结果

在 1,335 个验证窗口上，参数自由的因果输入上限结果如下（单位：米）：

| 指标 | P95 | 最大值 |
| --- | ---: | ---: |
| `q0` 固定槽位误差 | `8.20e-7` | `2.81e-6` |
| 0.5 s 平移运动误差 | `2.29e-5` | `3.45e-5` |
| 0.5 s 旋转运动误差 | `1.27e-5` | `2.37e-5` |
| 0.5 s 平移+旋转运动误差 | `3.64e-5` | `7.48e-5` |
| 0.5 s 静止运动误差 | `0` | `0` |

所有验证样本均低于 1 mm。A/B pilot 的最佳 checkpoint 都选择 epoch 0 的共同物理主解，headline 运动 P95 为 `2.74e-5 m`。继续更新神经残差会把验证误差推到毫米级，因此早停正确拒绝了这些更新。

这个结果说明：在严格恒定运动的干净物理层，主要误差已经被解析刚体约束消除，神经残差没有可重复的目标。神经网络的真正作用应出现在后续非理想层，例如带噪 PnP 历史、短时非匀速或鲁棒状态适配；不能为了显示“训练有效”而破坏已经正确的物理解。

## 仍未完成的边界

- 尚未访问 test，也未进行多 seed 指标发布。
- 尚未证明 PnP 坐标下的同等精度；远距离 PnP 系统误差不属于本物理实验。
- 固定真值槽位只代表外部因果身份状态机的接口假设，在线丢失与重建逻辑仍需单独接入验证。
- 尚未导出 ONNX/TensorRT，也未接入 tracker、MPC、火控或实弹。
